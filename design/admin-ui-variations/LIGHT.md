# Crazy Seal Admin: light mode concepts

The attached screenshot is the REAL, built Crazy Seal Admin in its dark mode
(1536×960): blue glass sidebar with the Crazy Seal logo (a cartoon seal in
green and blue), a gold "Sales" number, a gold selected-range pill, glass
panels, and a right-hand "Activity" rail (orders waiting to ship, latest
orders, dealer applications, sync status).

Generate light-mode versions of THIS exact screen, as images (1536×1024,
flat, full-frame, no device frame). The owner's rule:

- The **left sidebar keeps its colour scheme exactly**: the same deep blue
  glass gradient, the logo, gold active bar, white text, blue and gold
  count pills. Do not lighten the sidebar.
- **Everything else turns light**: page background, top bar, KPI tiles,
  panels, tables, chart area, and the activity rail.
- Keep the same layout, the same content and numbers, the same compact
  density, crisp 1px borders and the gold accents. Blue stays the primary
  data colour (chart columns, links, Paid badges). Gold marks the most
  important things: the Sales number or tile, the selected range, the
  "13 orders waiting to ship" call-out, the "Review applications" button,
  the "28" count. On white, gold must not be used for small text: use it as
  a fill or underline with dark text on it.
- Text must stay legible and correctly spelled. Prefer the exact text from
  the screenshot.

Save each image to `./concepts/` with the file name given in your task.
